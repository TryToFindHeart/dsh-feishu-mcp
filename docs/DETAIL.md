# 飞书结束通知 · 插件详情

## 它解决什么

DSH 在后台跑完一轮任务后，用户不一定盯着界面。插件把结果（完成 / 出错 / 达到上限）以飞书卡片的形式推送到群里，并可选 `@all` 做强提醒。

## 为什么用自定义机器人 webhook

出站通知只需要一个 URL，不需要公网回调、不需要应用凭证，实现和运维成本最低。webhook 本身即为密钥，因此：

- 不写进 `cordis.patch.yml` 或普通 Config；
- 不回传给浏览器原文，只回末 8 位掩码；
- 落盘到 `~/.dsh/dsh-feishu-mcp/state.json`，写入时 0600 + 原子替换。

## 事件选择

只消费 durable 事件：

| 事件 | 作用 |
| --- | --- |
| `turn/start` | 记录开始时间 |
| `assistant/message` | 记录最后一段助手正文 |
| `turn/end` | 汇总并投递 |

取消的轮次不播报；子代理轮次跳过，由父会话统一汇报。这样既不漏最终结果，也不会重复提醒。

## 卡片构造

正文先按 Markdown 块切分（表格、代码围栏、水平线单独成块），超长块再按行拆分，按 6000 字预算分页，最多 6 张。表格默认转成 Markdown，避免部分飞书客户端拒绝原生 `table` 元素。卡片失败时降级成纯文本，保证消息不丢。

## 设置页

通过 `settings.section` 插槽注册到侧栏 Settings。页面通过同源 Fetch 调用 Host 的精确路由 `/api/feishu-mcp/{state,config,test,clear}`，不直接持有 webhook。

## 当前边界

- 只支持出站；入站私聊消息订阅尚未接入。
- 不做流式回写；只在轮次结束时发一条最终结果。
